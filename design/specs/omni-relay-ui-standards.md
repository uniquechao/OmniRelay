## 布局和滚动

- 桌面侧栏宽 166px，收起为 52px。拖动侧栏右沿或点击收放按钮切换，拖动释放时吸附至对应档位。键盘可聚焦拖拽柄，用左右方向键、Home 或 End 切换。右沿只显示一条分隔线，悬停、拖动或键盘聚焦时高亮同一条线。展开状态保存在本地显示偏好中。
- 侧栏支持一级项和可展开的二级组。当前子页只标记一个。开发者组包含列表页、表单页、信息展示页、组件列表、工作台布局说明和色彩系统。520px 及以下以顶栏分组下拉承载导航。
- 底部入口展示当前用户。用户菜单显示用户名、角色，并提供个人信息、修改密码和退出。原型内账号操作均使用本地示例。
- 展开侧栏时，用户入口上方展示系统状态，包括 CPU 使用率、内存已用／总量和磁盘已用／总容量。原型读数标为示例。收起侧栏时隐藏指标区。
- 顶栏基准高 46px，放置当前位置与全局操作。主区桌面左右留白 22px，窄屏 14px。内容随字号放大换行。
- 标准列表的工具栏独立成框，常规一行，有筛选摘要、选中项或次级操作时使用第二行。额外筛选、选择模式进入可收起的浮层。
- 列表区填满标题、工具栏和分页之间的空间，内容超出时仅在列表区滚动，表头留在列表区顶部。表单、项目概览和信息展示页由主内容区上下滚动。极窄、极矮或放大字号时，主内容区可以滚动以保留控件可达性。
- 标准列表页标题下直接接工具栏，页面级操作与标题同排。
- 运行记录等独立列表直接使用工具栏和表格结构。摘要之外的列表页不再加标题相同的外层面板。
- 浮动提示锚定工作区顶部中央，叠放时最多三条。信息、成功、警告、错误使用蓝、绿、琥珀、玫红，加文字级别。默认 6 秒关闭，支持手动关闭，鼠标悬停或键盘聚焦时暂停。字段错误和需要后续处理的错误仍可在对应内容区域持续显示。

### 飞书登录和系统管理

- `#/login` 提供演示账号密码登录和飞书授权演示。个人菜单退出后返回登录页，重新登录可回到退出前的工作台页面。
- 登录表单背景使用淡栅格。产品标语固定在品牌区上方，四圈波纹围绕 Logo 交替反向旋转。每组 3–6 个 `0`、`1` 字符从不同方向汇聚，字符朝向与流动方向一致。Logo 以两下轻重不同的起伏模拟心跳。系统开启减少动态效果时显示静态画面。
- 「系统管理」下的用户、角色和审计页复用标准列表。用户管理用组织树筛选用户，标题栏提供「同步」和「同步详情」。同步详情显示当前进度和上次结果，示例同步完成后刷新组织树与用户列表。
- 用户详情从角色列表底部添加一行并就地保存。项目级角色按用户已加入的项目授权，重复授权展示表单错误，关闭有草稿的抽屉时提示保存。启停和撤销需要确认。
- 角色权限详情展示授权范围、适用条件和可执行操作。新增和撤销授权通过用户详情完成。
- 审计详情展示操作者、对象、时间、结果和变更摘要。登录、退出、账号启停、角色授权变更和目录同步在同一原型中即时留痕。数据在当前页面内存中演示，刷新重置。

## 对话框与浮层

| 类型 | 用途与动作 |
| --- | --- |
| 信息查看 | 快速查看对象名称、状态和属性，提供关闭操作 |
| 表单编辑 | 在当前页面短编辑，进入时聚焦首字段，底部是取消、保存，校验错误显示在表单内 |
| 操作确认 | 显示受影响对象和操作后果。启用与退出用普通强调，禁用用警告色，删除用危险色。确认按钮写具体动作，初始焦点落在取消 |
| 右侧抽屉 | 保留列表上下文时用于读详情或编辑。点击遮罩空白、关闭按钮或按 Escape 都进入关闭流程。编辑有改动时提供保存并关闭、不保存和继续编辑 |
| 锚定弹层 | 筛选、下拉和用户菜单在触发器附近展开 |
| 顶部提示 | 短暂反馈结果，默认 6 秒消失 |

模态对话框采用标题区、可滚动内容区和右对齐底部操作。右上角关闭按钮和 Escape 都可以取消。关闭后焦点回到触发器。若行已删除，焦点回列表区。

## 颜色

品牌靛蓝 `#6553F4` 与青绿 `#00A69A` 源于 OmniRelay Logo。界面角色色使用 `--or-primary`、`--or-focus`、`--or-agent-bg` 等主题变量。优先选用角色色，然后选择对应的品牌色阶。开发者的色彩系统可切换浅深色、复制 HEX，并查看简报与分派示例。

| 角色 | 交互规则 |
| --- | --- |
| 主操作 | 靛蓝实色。悬停和按下使用各自色阶，禁用使用中性表面与文字 |
| 次要操作 | 淡靛蓝底，悬停、按下有独立色阶。取消、关闭和重置使用中性底 |
| 焦点与错误 | 键盘焦点用统一靛蓝轮廓。字段错误用玫红边界、就近文案和焦点定位 |
| 选中 | 页签、表格、筛选、选项和日期使用靛蓝选中态，组织树保留青绿选中态 |
| Agent 与状态 | Agent 摘要、提示用青绿。成功、警告、错误及进度使用各自的文字和背景配对 |
| 语义按钮 | 信息用蓝色，成功用绿色，需留意的确认用琥珀色，危险操作用玫红色。普通表单保存使用主操作靛蓝 |
| 侧栏与浮层 | 侧栏保持深底和青绿激活图标。弹层、提示、对话框和抽屉按统一表面、阴影与遮罩变量展示 |

工作台各页、嵌入和独立色板、飞书卡片预览共用 `omni-relay-colors.css` 和 `omni-relay-interactions.css`。嵌入色板与工作台双向同步主题，从工作台打开的独立预览继承当前主题。

## 加载状态

2026-11-19 起统一复用 `omni-relay-loading.js` 和 `omni-relay-loading.css`。大页面采用用户指定的 `omni-relay-logo-loading.html` 中“循光成环”双弧 Logo 动效、品牌字标与进度条；区域采用 48px 小 Logo 和 164px 进度条，按钮使用更紧凑的同款组合。

- 页面初始化、会话检查使用 `size: 'page'`；列表、同步和验证使用 `size: 'compact'`；提交按钮用 `OmniRelayLoading.button`，由实际请求控制显示和移除。
- 有实际进度时传入 `progress`（0–100）；未知进度时显示往复等待条，不自动计算百分比或假完成。Logo 入场动画结束后仍等待任务结果，不能为播放完整动画延迟展示页面。
- 失败转入错误与重试状态，完成移除加载状态；后台刷新保留已有内容。演示同步与 Bot 检查继续使用明确标记的示例步骤。
- 浅深色跟随主题变量。减少动态模式显示完整静态 Logo 和静态等待条；页面隐藏及区域离屏时暂停动画。等待状态不抢焦点，进度条有名称，百分比仅在可测量时提供。

从“开发者 → 组件列表 → 加载状态”查看页面、区域和按钮效果。正式工作台通过 Go 内嵌相同组件资产。

## React 共享组件

业务页从 `frontend/src/ui/components` 导入下表中的导出。`WorkbenchLayout` 在工作区内提供 SVG 符号和全局消息播报区。独立页面在根部挂载一次 `VisualResources`。组件入口按原型顺序载入主题、工作台、控件、富文本和动效样式。品牌色、控件填充、文字、边框、焦点、风险、图表和头像取色统一使用 `--or-*` 语义变量。

| 原型位置 | 组件导出 | 用法、视觉状态和交互 |
| --- | --- | --- |
| 列表页、组件列表 · 列表组件与行操作 | `DataList` | 传入稳定字符串 `id` 的记录、列、搜索函数和可选筛选。列用 `text` 显示文本，用 `render` 嵌入 React 元素，用 `sort` 开启排序。按行配置操作标签、可见条件与回调；确认和数据更新由业务页接管。搜索、空结果、分页、选中摘要、键盘调宽沿用原型。`onSelection` 返回记录 ID。 |
| 表单页、组件列表 · 文本填写框 | `FormGrid`、`Field`、`TextField`、`TextArea`、`Button` | 字段使用可见标签；`Field` 的 `id` 对应子控件。输入组件透传原生表单属性，`error` 关联错误说明。网格随宽度由两列变一列。按钮支持普通、主操作、信息、成功、警告、危险、禁用和忙碌；提交按钮传 `type="submit"`。 |
| 信息展示页 · 概要、项目说明 | `Panel`、`Facts`、`Multiline` | 按标题组织分段，键值对使用 `items`，值可放状态标签。多行正文保留换行，可键盘聚焦后滚动。 |
| 组件列表 · 状态显示 | `Status` | 传 `tone` 和可读状态文字；圆点、底色与文字色随主题切换。禁用映射到中性待办色。 |
| 表单页、组件列表 · 搜索下拉、人员选择 | `SearchSelect`、`PersonSelect` | `name` 写入表单，`choices` 提供稳定 ID、标签、可选组织说明和检索串，`multiple` 开启多选。方向键移动、Enter 选择、Escape 关闭，多选标签可移除。`onChange` 接收 ID 数组，表单使用逗号分隔的 ID；标识符应不含逗号。 |
| 信息展示页、组件列表 · 人员单个展示 | `PersonCard` | 传入 `personKey`、姓名、组织和来源。头像按稳定标识分色，姓名和头像均能打开资料卡，Escape 关闭。 |
| 表单页、组件列表 · 组织树和组织选择框 | `OrganizationTree`、`OrganizationPicker` | 提供含 `id/name/parentId` 的节点。树支持同级互斥、展开全部、收起全部；`selectBranches` 控制分支能否选中。选择器受控于 `value/onChange`，确认后回填 ID 和完整路径，清除后焦点回到选择按钮。 |

| 组件列表 · Markdown 显示框 | `Markdown` | `source` 传原文，支持渲染与原文切换、围栏代码高亮和键盘滚动。沿用原型禁用内嵌 HTML 的解析器。 |

### 工作台路由与共享组件接线

菜单、页面标题、面包屑、移动选项和登录返回目标统一读取 `frontend/src/routes/targets.ts`。路由项提供正式路径、历史别名、分组、标题与能力键；资源页可通过 `parse` 返回规范路径和上下文标题。菜单显示使用会话中的导航及分项能力。资源标识的匹配可复用 `matchPattern`，例如 `/#/sample/projects/:project/files/:file`。测试注册表及样例见 [workbench-routes.test.mjs](../../tests/contract/workbench-routes.test.mjs)。资源页面上线时将正式定义和跨端路径样例一起接入。

登录使用 `BrandMotion`、`ThemeToggle`、`TextField` 和 `Button`；账号资料与改密使用 `Dialog`、`Facts` 和表单字段；工作台使用 `WorkbenchLayout`、`Breadcrumbs`、`Icon`、`Panel`、`Loading` 与全局提示。既有业务页通过专属挂载节点和取消信号接入，草稿视图提供 `confirmNavigation` 和 `hasDraft`，并在组件卸载时释放刷新监听器。Go 在 OAuth 回调时重新检查页面能力，对具体项目、会话使用对应服务的读取权限。
