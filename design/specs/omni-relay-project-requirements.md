# OmniRelay 项目模块需求

2026-11-18 · v0.1 · 需求评审稿

项目成员能在工作台看清项目进展、关键节点和自己的任务，从飞书群聊或私聊发起即时查询。项目负责人能维护项目档案和人员分工，确认正式任务，设置项目群与简报发布计划，并追查操作和交付结果。

本稿参考 OmniGrid 的正式项目列表和八栏工作台，以 OmniRelay 已确认的视觉、标准组件和飞书交互为界面基础。首期建议延续当前服务设计，由 OmniGrid Business API 提供正式项目、成员、任务和来源权限，OmniRelay 承载项目工作台、Bot 接入、简报计划和运行回执。此项为需求草案，数据归属与写能力仍需评审确认。

## 1. 入口与通用交互

### 项目列表

- 从左侧「项目列表」进入。默认显示当前账号可以查看的项目，按最近更新倒序。同一更新时间以稳定项目 ID 排序。
- 主列为项目名称、阶段、进展速览、负责人、更新时间。支持名称搜索、按阶段筛选、排序、分页、总数和每页条数。只在服务端可以提供准确总数时显示数字。
- 阶段沿用 OmniGrid 的规划中、进行中、受阻、已暂停、已完成、已归档。进展速览取最近一条仍可阅读的已确认进展。无记录显示「待补充」，依据不可访问或已变化时提示对应状态。
- 复用标准列表。标题下直接接工具栏，表格内部滚动，表头固定，列宽调整由相邻两列等量增减。支持单选、多选和清除选择。可用批量动作以明确授权和后端能力为前提。
- 「新建项目」在具备正式创建权限且写入接通后显示。项目名称必填，类型、背景、计划日期和业务时区按业务规则填写。可以先建无群项目，再关联群。编辑、暂停和归档由项目设置承载，状态变化写入正式历史。

### 项目工作台

- 项目标题区展示类型、名称、阶段和返回入口。栏目固定为 **项目概览、成员、群聊、会议纪要、文档、日报、任务、飞书 Bot**。
- 从现有项目简报链接进入时，定位到「日报 → 项目简报」。任务、群聊、纪要等可用稳定 ID 深链定位。返回列表恢复筛选、页码、滚动位置和触发项目行。
- 首次读取项目头和当前栏目。详情、正文和历史按打开读取。切换项目时停止旧请求，并丢弃迟到响应。窄屏页签可横滚，正文在内容区阅读。
- 表单与任务详情沿用右侧抽屉。关闭、切页和切换对象时保护草稿。版本冲突保留草稿，用户读取并核对最新版本后可重试。

## 2. 栏目需求

| 栏目 | 继承 OmniGrid 的主要能力 | OmniRelay 交付要求 |
| --- | --- | --- |
| 项目概览 | 项目档案、负责人、背景、计划、确认进展、关键节点、关注问题、项目记忆 | 首屏先显示可核对的事实。节点可关联正式任务，负责人和状态随任务变化。进展保留来源和确认时间。项目设置、访问说明、项目记忆和变更历史放在概览内的受控入口 |
| 成员 | 姓名及组织、岗位角色、分工、群关联、正式与静默成员、停用、变更历史、负责人交接 | 支持姓名及拼音搜索。展示正式成员与可提拔候选，统计过期或缺失时明确标明。移除负责人或有未完成任务的成员时，先通过正式交接核对任务和接替人 |
| 群聊 | 项目关联群、主群、消息、群成员及分工、搜索、历史分页 | 只展示当前项目内且当前账号有读权的群。可核对消息发送者和时间。项目群关联与 Bot 目标群需展示各自状态。全局「Bot 聊天记录」继续覆盖授权范围内的 Bot 所在群与员工 1:1 会话 |
| 会议纪要 | 按日期、来源等筛选，正文阅读、来源分享记录、同步状态、待办候选 | 列表按稳定源去重，一份正文可有多个分享来源。详情显示来源、更新或同步时间与原文入口。抽取的待办作为候选，须经人工确认进入正式任务 |
| 文档 | 关联飞书文档、电子表格、多维表格，分类、搜索、分页和项目内阅读 | 资料只来自用户当前有权访问的来源。可维护本地分类及关联，原文依照飞书权限打开。正文或表格部分加载时显示覆盖范围及继续读取入口 |
| 日报 | 成员日报明细、填报或代填、提交状态、摘要及跟进 | 分为「成员日报」和「项目简报」。成员日报保留原提交身份、来源和业务日。项目简报提供预览、计划、发布结果与历史。日报提交、同步状态和简报送达分别展示 |
| 任务 | 正式看板、负责人、任务标签、优先级、期限、验收条件、评论、操作动态与独立候选 | 默认四列为待开始、进行中、受阻、已完成。支持项目内搜索筛选、拖动和键盘移动。详情可跳转到来源。受阻填写原因，重开与取消按正式规则校验。配置列和删列迁移走正式命令 |
| 飞书 Bot | 项目关联对象及可访问的 Bot 入口 | 这栏用于查看和管理本项目接入。显示目标群、接入状态、允许范围、简报开关、最近运行和消息回执。角色和来源按项目复核。应用凭据及全局可用性验证保留在「系统管理 → 飞书 Bot 配置」 |

成员可以提交本人任务进展和受阻反馈，具备权限的负责人可以审核。任务评论、候选和管理跟进分别显示各自状态。受阻任务、确认问题及明确提出协助的已提交日报可以进入管理跟进，跟进结案不自动改写原任务、问题或日报。

## 3. 正式数据与权限

| 数据 | 建议事实源 |
| --- | --- |
| 项目档案、正式成员、访问策略、节点与问题、正式任务和历史 | OmniGrid Business API。OmniRelay 复用稳定 ID，读写使用正式接口 |
| 群聊、纪要、文档和成员日报 | 既有业务系统的已授权来源。读取时校验当前账号、项目关系和源版本 |
| Bot 群绑定、接入状态、简报计划、任务分派执行记录和消息送达 | OmniRelay。正式任务 ID 和写入结果取业务系统回执 |

- 使用可信的账号与成员映射识别 Web 和飞书发起人，同名人员用稳定身份区分。登录成功、属于同一部门或进入飞书群，都不能自动取得项目权限。
- 项目读权限约束目录、总数、搜索候选、详情和深链。来源权限还约束可见的群名、正文、原文链接和派生摘要。Bot 发往群里的字段须同时符合发起人、项目共享和该群可公开的范围。
- 正式成员按业务权限查看共享内容、更新本人可操作的任务，并能在明确交办时向同项目成员分派。项目负责人或获授权的管理员才能维护档案、人员、接入和发布计划中的对应操作。系统管理员、运维、审计能力与项目正文权限分别授予。
- 新增配置、授权、任务操作和发布均记录操作者、对象、时间、结果和关联编号。配置、任务写入和飞书送达分别显示状态。回执未知时用原操作编号对账，重试不得重复建任务或发简报。
- 账号停用、成员退出或来源撤权时，后端重新鉴权，界面清理已失权的内容。临时服务故障保留仍有权看的内容并显示截至时间。空数据、未知、未接入、失败和失权分别反馈。

## 4. 建议交付顺序

| 批次 | 交付项 | 进入下一批的条件 |
| --- | --- | --- |
| 先定稿原型 | 项目列表与八栏全部设计。优先串通概览、成员、任务、项目简报、项目 Bot 和全局 Bot 聊天记录 | 能走通桌面和手机的查项目、查任务、回看 Bot 结果以及项目设置入口 |
| 第一批可用 | 真实项目列表和概览，成员、任务只读，项目 Bot 绑定及联调，项目简报预览与运行结果。其余栏目按真实接入状态显示 | 完成可信身份映射，核对 OmniGrid 的按项目读权限、任务数据及至少一个项目群的接入 |
| 第二批业务操作 | 接入官方写能力。档案修改、正式成员维护和交接、任务看板操作、明确交办、简报发布 | 写入、冲突、审计、回执重试和撤权用例通过。自动发布可按项目独立启停 |
| 第三批资料与跟进 | 项目群聊、会议纪要、文档、成员日报的正式读取、来源管理和跟进。逐项补齐同步、统计与历史能力 | 按来源类型核对授权、分页、撤权和同步边界。群聊手动发送另行验证发信身份、目标范围和回执 |

## 5. 验收场景

| 场景 | 可验证结果 |
| --- | --- |
| 从列表进入再返回 | 搜索和阶段筛选在授权范围内生效，返回到原页和原项目行 |
| 不同账号访问同项目 | 能力入口随角色变化。无权项目不出现在搜索和总数里，直接访问深链也不返回详情 |
| 群聊与员工 1:1 | 北辰项目群可从项目内回看已授权消息。员工私聊从全局 Bot 记录按会话权限查看，项目群入口不会混入私聊 |
| 看板、节点与任务回执 | 执行一次验收任务分派后只产生一条正式任务。节点与看板展示同一状态，Bot 回执可跳转该任务 |
| 目标群变更或撤权 | 已生成的简报在发送前检查最新群绑定与可公开范围。失权来源内容及原文入口从阅读页移除 |
| 正式写入冲突 | 两人先后提交同一项目或任务版本时，后提交者看到冲突，草稿留在抽屉里供比对 |
| 日报同步失败 | 已确认的正式提交继续可读。采集范围不足时显示未知，不能据此标记漏交 |
| 简报重复触发与发送未知 | 同项目、业务日和目标群的常规简报只执行一次。发送未知保留对账入口，不显示已送达 |
| 不同设备操作 | 桌面与窄屏均可浏览八栏和操作有权功能。键盘可进入列表、页签、看板和抽屉，并在关闭时回焦 |

## 6. 待定决策

1. **正式项目归属**。建议第一阶段直接复用 OmniGrid 数据和命令。如果目标是 OmniRelay 独立管理项目，需先确定档案、成员、任务和历史的迁移边界，再设计独立模式。
2. **首次接通的写能力**。建议先通同项目任务分派，再开放新建项目、人员交接和看板配置。正式部署前要核对各操作在 OmniGrid 接口上的身份与授权条件。
3. **试点验收样本**。选一个已关联飞书群、具备正式任务和两种业务角色的项目。明确普通成员和项目负责人各自可以看到的资料、可分派范围，以及简报默认预览或自动发布。
