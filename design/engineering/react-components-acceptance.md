# React 共享组件验收

本次交付覆盖原型「开发者」六个入口。业务导入入口为 [components/index.ts](../../frontend/src/ui/components/index.ts)。各组件的参数、状态与接入示例见[开发规范](../specs/omni-relay-ui-standards.md#react-共享组件)。

同一份组件样例经 Vite 构建后，在本机 Chromium 实测 1366×900 和 390×844。每个视口分别以浅色和深色进入，并在页面内切换主题。浅色起始场景使用正常动效，深色起始场景开启减少动态效果。四组均通过。键盘检查使用真实焦点、按键和表单事件。样例只提供测试数据，业务路由及认证由后续迁移接入。

| 原型位置及导出 | 桌面、窄屏与主题实测 | 交互、键盘与动态效果实测 |
| --- | --- | --- |
| 列表页、行操作 · `DataList` | 工具栏和行按钮的渲染样式与原型一致。搜索 12 条记录中的指定行，行操作回读正确记录，第二页显示 2 条 | 切换单选模式，选中数为 1；点击排序后表头标记升序。分页后自定义 React 单元格仍显示状态标签 |
| 表单页 · `FormGrid`、`Field`、`TextField`、`TextArea`、`Button` | 两种视口均能定位可见标签、填写和提交，表单回读保留备注与日期 | 通过可访问名称操作输入框和提交按钮；忙碌按钮禁用 |
| 信息展示页 · `Panel`、`Facts`、`Multiline` | 分段概要可读，键值项承载状态标签；两行只读文本保留原有换行 | 只读滚动区有键盘焦点入口，内容验证使用呈现文本 |
| 组件列表 · `Status` | 同一表格上下文中比对成功态的底色、文字、圆角、内边距、字号、字重及最小高度，浅深色一致 | 状态文本保持「已完成」，与圆点同时呈现 |

| 抽屉与对话框 · `Drawer`、`Dialog` | 标准、加宽抽屉在桌面分别为 480、720 像素；在 390 像素视口均收窄至视口宽度 | Enter 打开确认框，Escape 关闭并还原触发焦点。编辑后关闭触发草稿确认，继续编辑回到字段，不保存回到原按钮。减少动态效果时同样可完成 |

| 色彩系统 · `ThemeToggle`、`ColorPalette`、`ColorSwatch` | 亮靛蓝、青绿以及五组功能色和状态色引用原型变量。切换主题后主按钮色值更新 | 键盘激活色块，实际读取剪贴板的颜色与当前显示一致。减少动态效果模式可切换主题 |

## 比对结论与边界

定向用例在同一浏览器、视口和主题下打开原型组件页与 React 样例，对十个控件位置比对背景、文字颜色、圆角、内边距、字号、字重和最小高度，四组环境的断言全部通过。状态标签的字重会继承所在容器，比较时两端均取列表单元格。色板按可嵌入的分组展示；核对范围包括变量、主题切换和复制值。此次视觉结论限于测量项，未做整页像素差分或真实读屏器测试。

复现命令为 `TMPDIR=/tmp node --test tests/integration/react_components.test.mjs`。测试构建独立样例并从同源静态服务加载资源，可用 `OMNIRELAY_CHROME` 指定浏览器路径。[定向浏览器用例](../../tests/integration/react_components.test.mjs) · [组件组合样例](../../tests/fixtures/react-components/sample.tsx)

## 工作台、登录与历史入口联调

| 入口与组件 | 环境及操作 | 结果 |
| --- | --- | --- |
| 登录 · `BrandMotion`、`ThemeToggle`、`TextField`、`Button` | HTTPS 下输入密码，核对桌面和 390 像素窄屏的品牌区、浅深色及画布帧；在减少动态效果和正常动效之间切换 | 密码登录及改密通过；减少动态效果时画面静止，正常模式持续绘制 |
| 飞书登录与反馈 | Chromium 经授权页跳转至真实 Go 回调；飞书端为测试提供方。分别执行成功、取消、拒绝和服务不可用，再次授权 | 登录成功回到有权访问的书签；取消后刷新仍保留目标，拒绝及失败有可读反馈并可重试 |
| 账号菜单 · `AccountTrigger`、`Account`、`Dialog`、`Facts` | 键盘打开菜单和资料，Escape 关闭；密码登录用户改密、确认退出；另一标签页切换身份后复核 | 焦点回到账号按钮，退出回到登录，旧账号资料弹窗关闭 |
| 工作台与导航 · `WorkbenchLayout`、`Breadcrumbs`、`Overview`、`Panel` | PostgreSQL 16、Go HTTPS、React 构建、Chromium，使用管理员、运维、审计、普通用户及具项目权限的运维账号 | 桌面菜单与移动选项符合角色矩阵，历史入口归一并高亮；书签直达、后退、前进、撤权回落通过；缺少导航能力时显示无可访问页面 |
| B2 正式页及确认框 | 从连接设置书签进入 Bot 配置，编辑后尝试刷新、后退；先继续编辑，再放弃草稿并前进 | 刷新触发浏览器提示，继续编辑保留值和焦点，放弃后进入目标页面；临时无法核验身份时页面锁定，恢复后保留同账号业务草稿并清除密码 |
| 路由定义与服务端授权 | 两端读取 `tests/fixtures/workbench-paths.json`；Go 另行验证项目与会话读取权限，参数化路径在测试注册表运行 | 正式路径和别名、未授权角色、未知或外部目标以及仅测试的资源模式符合预期 |

浏览器针对本地测试账号及测试飞书提供方执行。定向用例位于 [登录与草稿回归](../../tests/integration/feishu_login_browser.test.mjs)、[角色与历史入口矩阵](../../tests/integration/system_roles_browser.test.mjs) 和 [Go 回调与共享样例](../../internal/identity/identity_test.go)。
