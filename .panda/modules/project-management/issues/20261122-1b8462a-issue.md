# #20261122-1b8462a 项目文档

## 原始需求

项目中文档改成文件
交互页面改成文件网盘一致

## 澄清与设计

以附件中的七个分类、搜索与筛选、八列表格和行操作为界面基准。沿用项目页签地址 `/docs`，共享网盘列表。项目原有本地来源按阅读授权并入列表，保留关联任务入口。

## 设计与实施

项目列表在服务端合并通过来源授权的网盘记录与当前账号可读的本地文档，再统一筛选、排序和分页。项目上下文贯穿网盘文件预览和下载。

## 修改文件与测试

- `web/projects.js`、`web/drive*.js`、`frontend/src/features/workbench/Workbench.tsx` 和共享列表样式接入七类文件、分享时间倒序、搜索筛选、预览、下载与来源定位。
- `internal/project/http.go`、`internal/project/panels.go` 和 `internal/drive/` 共用文件查询与分页。历史本地文档归入「文件」，按需读取正文、下载纯文本，并保留「查看关联任务」。
- 前端构建通过。已对照附件查看桌面渲染。五个浏览器定向场景通过，覆盖桌面及窄屏、浅深主题、旧深链、项目切换、来源回焦、筛选、抽屉、图片视频及本地文档下载。
- 四个 Go 定向用例通过，涉及存储的用例使用隔离 PostgreSQL。验证分类和分页、分享时间排序、跨项目版本隔离，以及撤销阅读权限后的列表与正文访问。

## 结果与遗留事项
