# 项目关注与侧栏快捷入口

用户希望关注项目后能从工作台左侧菜单直接进入项目详情。项目列表和详情页提供同一关注操作，个人关注保存在账号的项目成员记录中。侧栏仅展示当前账号仍有权访问的项目，点击打开项目概览。

同批修复浏览器标签页的默认地球图标，工作台沿用首次配置页的 OmniRelay 品牌图标。

独立 PostgreSQL 已通过项目服务及迁移回归，覆盖普通读者、重复操作、跨账号隔离、已有会籍、项目改名归档、停用账号和撤权。使用真实登录的 Chrome 验证了列表关注、折叠侧栏展开、跳转概览、刷新及另一账号独立取消关注。浅色、深色与移动导航回归通过，工作台与首次配置入口均成功加载同一品牌图标。

较大浏览器套件另有五项旧基线失败，已在改动前的 `1238113` 上复现，涉及许可证资源清单和旧任务看板夹具。

生产集成基线为 `e903bcf`。已保留已上线的迁移 38，将项目关注迁移编为 39。合并后的版本已通过含历史成员记录的 38 到 39 升级、项目服务与迁移测试、双账号真实浏览器测试、桌面及移动导航、标签页图标、类型检查和生产构建。发布制品与线上只读验收结果归档在本地发布记录 `release-personal-project-follows`。
