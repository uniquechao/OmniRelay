# 项目角色与人员选择统一

用户截图确认：项目成员角色取系统角色权限中的项目级角色；项目添加人员从用户体系选择，任务负责人和参与人同样使用用户选择器。

采用系统角色目录 ProjectRoleDefinitions，仅返回 project scope。角色授权复用系统 grant/revoke 领域命令，资料版本和角色观察值防止旧草稿覆盖外部授权。人员使用启用系统账号，项目新增排除已入项账号，任务选择限定当前有效项目成员。保留旧会籍角色兼容与最后负责人保护，职责继续单独编辑。

代码回归通过：独立 PostgreSQL 下 access/project/directory/group 模块；新增角色目录一致性、实际授权与撤权、越权拒绝、旧草稿冲突、旧会籍兼容及审计回滚验证。真实浏览器通过成员添加/编辑/移除、任务负责人和参与人选择、双账号权限以及桌面/手机浅深主题；插件验证 canonical 项目角色添加、筛选与降级。TypeScript 检查及前端构建通过。证据仅保存在本地忽略目录，真实生产发布及用户签收另记。
