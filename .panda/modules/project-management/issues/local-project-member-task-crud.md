# 项目成员与任务管理（会话任务）

## 原始需求
允许添加项目人员、修改项目角色及职责；任务支持增删改查。以现有原型为基准，同步扩展 DSH 插件以实现相同业务效果。

## 设计与实施
基线 c2a466b。原型成员详情已有项目角色、项目分工展示；任务详情已有编辑和状态流转。沿用右侧抽屉、搜索及确认流程，补齐成员管理入口、任务创建与删除。访问角色与业务角色名称分开存储。网页和插件共用领域命令、版本检查与权限；成员有未完成任务时先交接，保护最后一位负责人。任务逻辑删除保留评论、来源、审计但退出业务查询。

## 群成员候选

添加成员与任务指派使用项目关联群的有效成员快照并去重。任务选人可在成员首次登录前保存，正式添加项目成员时沿用任务中的身份。浏览器覆盖两个群重名搜索、跨群去重、跨项目隔离、多选保存与正式添加。
