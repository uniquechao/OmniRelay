# 项目任务看板独立复刻

OmniRelay 项目工作台采用 2026-11-22 OmniGrid 交付包的看板、检查器、候选确认和设置组件。交付包的 `checksums.sha256` 已核对。移植在独立工作树的 `feat/project-task-board-replica` 分支完成，基线为 `a384837`。

## 实现与兼容

- 项目「任务看板」挂载原版 React 工作区。原版的看板布局、卡片、筛选、检查器和设置使用随包组件与样式。基础弹层、菜单、组合框分别接入 Radix UI 和 React Aria。
- 看板读取当前登录会话和项目会籍。四个默认状态、可编辑列、任务编号、筛选分页、任务字段和候选处理接入 PostgreSQL。旧任务链接、列表编辑、里程碑及软删除入口继续使用。
- 迁移 0037 为旧任务分配项目内稳定编号。移动和删除列时在事务内迁移整列。候选确认需要重新核对来源权限与修订，合并仅关联依据。

## 验证

- TypeScript 类型检查、Vite 生产构建和 Go 全仓测试通过。带 PostgreSQL 的项目与迁移测试通过。

详情抽屉独立铺满视口高度。参与人位于主负责人下面，可按姓名与拼音检索、多选。详情在同一数据库快照内从活动和反馈记录提取实际互动成员，合并手动选择后去重展示。已有记录直接参与计算，无需数据迁移。任务编辑授权继续读取明确指派的关系。评论采用单层输入框，标签支持在抽屉内勾选、创建和保存。

本次验证使用 Chromium、真实登录会话和独立 PostgreSQL。已走通切换状态与布局、批量更新优先级、选人、勾选及创建标签、保存后在手机重新打开。两账号验证了只读访问和重复评论的参与人结果。桌面与手机均测量了抽屉的顶部和高度。项目、迁移、Go 全仓回归、TypeScript 与前端生产构建通过。

## 旧任务列表书签

## 任务取消、删除与项目工具

截图中的变更原因留空。服务要求取消或重开终态任务时提供原因，原抽屉允许直接提交。抽屉现在在本地提示原因并定位输入框，允许任务管理者带原因确认删除。验证覆盖取消后的筛选、放弃删除、移除任务和读取已删除任务。

本次把网页任务业务操作与 Gateway 的项目工具目录逐项对照，补齐看板、批量操作、证据、进展建议、候选、标签和里程碑。工具经认证的项目工作事务调用同一领域命令。私有候选和反馈按已读取记录核对，正常审核后仍可核验原始材料，撤权时中止。工具清单和授权在项目经理工具能力文档中维护。

## 深色看板

## 任务详情与验收条件

两处正文默认显示已渲染的 Markdown，分别编辑和预览。图片、文件可通过粘贴和文件选择加入。附件随任务保存事务提交，冲突或取消的草稿不会落库。附件按当前项目和有效任务读取，可内联展示的栅格图片按实际内容判定，其他文件下载。历史纯文本任务兼容。

## 状态栏与看板列之间的留白

去掉任务头部的 14px 底部外边距，各列顶边直接接到状态筛选栏底边。Chromium 在 1440、1100、820、390、320px 视口检查两条边的坐标，列间距及栏内操作区沿用原布局。验收截图位于本地工作树的 `.runtime/board-evidence/`。

## 平铺任务列表

列表模式复用系统 DataList。状态标签页用于筛选，表格按整个结果排序和分页。每行显示编号与标题、状态、优先级、负责人、开始日期、截止日期、标签及操作。日期与标签可按展示设置隐藏。

具备分派权限的成员可以在行内调整日期、添加和移除标签。普通成员认领开放且未分配的任务后，可以直接调整任务状态。阻塞、取消与重开沿用任务领域的原因校验。“查看”打开现有详情抽屉。

本地浏览器回归覆盖跨状态排序、102 条任务翻页、日期保留原始精确时刻、创建与移除标签、只读账号与双账号竞争认领。桌面浅色和手机深色截图在 `.runtime/board-evidence/task-list-1440-light.png` 和 `.runtime/board-evidence/task-list-390-dark.png`。
