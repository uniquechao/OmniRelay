# 项目简报

项目 PM 可按业务日期读取、创建和修改一篇项目成员共享的简报。概览展示最近一期，简报列表按日期倒序分页，点击整行可进入详情，支持刷新与返回列表。

持久化按项目和业务日期唯一，版本冲突返回 409。项目设置权限控制编辑，项目读取权限控制查看。已有生成记录保留原可见范围与群投递详情，同一日期优先展示已撰写的简报。

验收覆盖插件的日期校验、读写角色和版本冲突，以及浏览器中的概览、列表和详情往返。

补齐了周报取证路径。PM 可按区间搜索已保存简报的当前版本，并分别核对成员日报和群投递回执。群消息检索按项目本地业务日、群和可选关键词筛选，引用保留消息 ID、时间及已知发言人。周报写明确认进展、待核实事项、行动与查阅范围，草稿、项目保存和群发布分别履行用户指示。数据库回归覆盖区间首尾、夏令时回拨、关键词命中长文、分页、撤回和来源权限，以及同日简报更新与已发布统计的隔离。

用户要求起草再确认时，项目 PM 展示候选简报的标题和完整正文。Gateway 将展示内容、目标业务日和当时的版本绑定。再次确认同一条目不会增加版本。用户要求直接保存时，同轮按授权提交。运行记录和对话链接使用数据库提交回执中的日期和版本。跨轮引用还需复核来源。旧会话没有可核验的候选条目时需重新生成草稿。

真实模型验收用例为 `TestRealModelBriefConversation`。它从工作台接口发起请求，使用隔离 PostgreSQL、双向 TLS 的 Gateway 与 Runtime、正式模型和合成项目资料。随机生成的纪要和群聊编号用来核对实际取证；下一周的首条消息用于核对日期边界。测试还逐字对比预览与落库标题、正文，并核对重复确认后的数据库版本。
