本次交付以成员在绑定群 @Bot 询问「我是谁」为入口。复用项目档案、群归属和正式成员授权。

| 工作包 | 验收行为 |
| --- | --- |
| Gateway 与持久工作 | 接受同一消息两次只有一个工作，群重绑、成员撤销或重新加入后旧工作失效 |
| Runtime 镜像与只读工具 | DSH 会话仅暴露身份工具。真实工具在 Go 根据当前工作读取四个字段。卷恢复后续用原工作 |

## 实施与取证

- Go 使用通道无关的 `group.Envelope`。正式成员表和群归属代次限定工作权限，迁移 30 分开保存业务工作和通道原始入站回执。飞书适配器在原入站事务内建立关联。
- Runtime 以非 root 身份运行，实例目录和 SQLite 接受日志位于卷上。只读插件使用本轮专属桥调用 Go。Go 在真实 DSH 轮次开始时登记会话和代次，并从真实工具回执生成署名和正文。
- 运行 `tests/integration/group-agent-gate.sh` 同时要求 `TestGatewayPermissionGate` 和 `TestRuntimeImageGate` 实际通过。模型只看到一个无参工具。已验证两个成员、服务身份证书、非法选择器、撤权、重放、容器重启及原话题交付。真实飞书身份和平台调用均不参与此门槛。
- 适配器测试 `TestGroupAgentInboxAdapter` 验证飞书原工作与内部工作对应，`TestGroupAgentReplyContract` 验证原消息寻址及话题回复参数。测试使用受控数据。真实外部收件和生产部署未执行。
- 群身份查询已覆盖同一持久卷恢复。跨节点自动接管和其他业务工具继续单独实施。

## 私聊和主动联系

- 用户私聊「我是谁」时，Gateway 依据入站私聊和已启用账号路由到全局查询助手。原群归属和会籍不会带入私聊，回程保留原私聊的消息 ID。
- 项目管理者可登记及停用单次提醒。迁移 31 记录计划、群与个人各自的授权和投递工作。Runtime 通过双向 TLS 发现归属自己的计划，DSH Harness 负责到点唤醒，Go 校验定时器和授权、按目标取数并投递。群内工具结果仅含项目字段。
- 内部验收脚本同时执行原两项门槛与 `TestPrivateReplyGate`、`TestDirectedNoticeGate`、`TestNoticePermissionGate`。新增门槛覆盖独立私聊、定时群发和个人定向、受众数据隔离、重复登记和回调、撤销计划及成员撤权。适配器用本地服务核验飞书收件类型和回执。验收使用内部 Channel。
- 实测在原生定时器绑定后、到期前重启 Runtime，沿用同一持久卷和定时器 ID，最终得到两个独立会话和两条回执。另在个人提醒完成只读工具调用后撤销收件人会籍，工作进入 `suppressed`，内部 Channel 未收到该条消息。

## 独立部署 DSH 服务

Runtime 使用单副本 StatefulSet、独立持久卷、集群内双向 TLS 服务与文件挂载的模型 Secret。进程存活、模型凭据已挂载、真实模型轮次分别验收。首次配置及轮换凭据均可从终端隐藏输入，显式模型探针使用隔离会话。环境和发布证据保存在部署交接目录。

## 工作台项目 Bot

项目「Bot」是站内通道，POST 只接受消息正文和重试键。服务从登录会话取得身份，按项目和会籍代次分开历史，核验工具回执并将模型原文与项目署名一起提交。Go 私有回调使用独立证书。原飞书接入状态及验证入口仍可由 Bot 页打开。

集群候选工作台使用隔离账号登录。项目成员第一轮核对到本人和项目，第二轮复述第一轮的随机校验词。两条署名回复对应同一 DSH 会话、两个轮次和两次有效工具回执。重复提交复用原工作，同项目另一名成员读取到自己的空历史，非成员被拒绝。这一验收通过站内通道完成。

另用 Chromium 在候选工作台以第二名项目成员登录，从项目 Bot 页面发问，收到带本人姓名和项目署名的真实模型回复，刷新后可恢复该条问答。两个成员在同一项目对应两个不同的 DSH 会话。

## 个人会话的草稿续办与来源复核

工作台个人会话和飞书私聊的每次业务提问新建原生会话。Gateway 按同一账号、角色、项目、渠道、话题、会籍与配置版本取最近四轮已展示问答。首次交付给运行时的轮次及其来源冻结于工作记录，重试读取同一份。收到独立执行计划时从当前请求和工具获取业务状态。群消息、自动委派工作和其他成员的个人记录不进入该上下文。

草稿的每个已展示条目由 Gateway 绑定。确认修改简报后，原简报版本会过期；正式业务写入、已消费条目和用户回执在同一事务完成。重启、丢失回调回执和重复确认均不能再提交该条目。来源撤权或修订会阻止旧稿及引用过它的后续答复继续传播。确认回执独立校验正式目标的当前权限。

迁移 50 保留旧会话、历史和写回执。旧版未记录个人上下文来源的答复留在原历史；此前已绑定原生会话且尚在运行的个人请求置为 `unknown / personal_session_upgraded` 以等待核查。验收包括 `TestPersonalContextRechecksTransitiveSources`、`TestConfirmedBriefSurvivesRevisionAndLostAcknowledgement` 和 `TestPersonalRevisionAndSelectedItem`，使用隔离 PostgreSQL 和受控模型结果。

工作台或飞书私聊收到“把刚才的分析写入简报”时，入站记录会绑定当时已展示的最近一轮答复，避免从排队中的问题取错正文。语义计划的 `prior_result` 记录当前用户的指代原文。Gateway 复核来源角色、项目会籍、角色配置、来源权限、版本和取证期间，将已展示的只读答复作为素材交给项目 PM。历史提问不授予操作权限；仅当前指令所列的动作可以生成正式回执。若上一轮是写回执、期间不符或来源不可用，Gateway 请用户重新指定。单项写入与回执同事务完成，记录原只读工作编号。回归包括 `TestExplicitPriorResultAsWriteMaterial`、`TestPriorResultFreezesWhatWasVisibleAtIntake` 和 `TestPriorResultRequiresCurrentAuthorizationAndScope`。


### 语义授权与工作恢复

入站请求通过 Runtime 的独立语义规划接口解释，仅发送认证用户本次原文和固定工具契约。Gateway 将角色、动作、目标及可生成的内容字段持久化，每条授权和对应写回执同事务消费。执行前核对角色配置、项目范围、当前会籍和领域版本。已展示的项目简报草稿按原正文及原业务版本确认；局部修订替代旧稿。跨项目委派冻结目标项目的子动作。升级前的未完成工作接续原回执，不能从历史自然语言取得新的写权限。

隔离 Gateway 与 Runtime 镜像门槛通过，包含 mTLS、三角色、委派、部分失败及项目工具矩阵。新增 PostgreSQL 测试覆盖动态生成的任务标题、跨动作调用、重复确认、历史请求及人工编辑后的简报版本。

报告取证期间独立于简报归档日期。上周按项目时区的上周一至周日、本周按本周一至受理日、指定日期范围按双端包含计算。首次执行将日期与时区固化在 semantic_plan.evidence_period，重试读取同一范围，带期间的独立报告使用有日期的工具读取资料。

编写有明确取证期间的简报时，Gateway 把期间与模型查询日期求交，并把实际日期和冻结的项目时区写入读源账本。周内群消息按发送时间、本地纪要按来源登记时间、飞书文件按分享时间筛选；用户单独指定的稳定文件引用仍须通过原来源授权。区间内的已存简报可以读取正文，全项目成稿目录另列日期、标题和版本；归档目标日期在区间外时只读取保存所需的版本。隔离 PostgreSQL 回归见 `TestBoundReportSourcesAndReplay`，覆盖扩大或省略日期、纪要越界、目录空结果、来源复核和普通会话。

语义规划通过受约束的模型工具结果传递。第一步仅判断用户意图、角色、指代和来源期间，草稿或正式执行才进入第二步生成逐项动作。两个调用共享截止时间。版本、代际和乐观锁前置条件只在业务命令侧取得，专用规划目录只描述文字、目标和可创作内容。模型返回的异常协议或缺少字段会重试，不会变成空计划或写权限。


### 飞书群直接回复与负责人提醒

生产群提问时，语义计划选择了普通读取，模型查询了群消息；正式看板有未完成事项。发送环节把已生成的正文替换成了工作台提示。现由 DeepSeek 根据提问选择当前未完成任务清单或普通群答复，同时给出明确提醒指令的原句。Gateway 在准备与发送两个时点核查授权、群绑定和正式任务。主群或唯一绑定群能得到最小任务清单，其他群仅展示公开消息能核实的内容。群成员标识由领域数据取得，到飞书投递前再次核验。

隔离回归覆盖普通消息与群话题、无任务、发送前已完成、重复投递、撤权或离群、同一人多项任务、长回复和普通文本中的伪造 @。受限来源的答复继续在发起人工作台展示。真实模型验收入口为 TestLiveGroupBoardReply 和 TestLiveGroupReplySemantics。

17:04:52 群简报在读取群消息后耗尽原生 60 秒预算。SQLite 只记一轮，后续 Gateway 重新领取 177 次时，新增在群答复上的来源受限标记改变了提示摘要，Runtime 在启动模型前拒绝。正式执行的超时现由 Gateway 按工作剩余时间和租约下发；同一工作重试可以更新截止时间，不能更换已冻结的 Agent、会话和请求内容。仅明确的不可变绑定冲突使用独立回执。原生 SDK 的延时群简报测试实际等待模型 61 秒，另覆盖截止后的恢复、写槽复用、旧租约和旧 Runtime owner 的请求。

### 飞书周简报在同一工作内续办

生产收到一条群内起草项目周截面简报的请求。原群消息正文未变，飞书补全发言人显示名时同时更新了消息时间戳，工具回执因此失效。首轮原生会话在 60 秒处中断。取数过程中设置的资料受众标记进入了下一次执行的提示，Runtime 拒绝恢复同一工作。请求截止前 Gateway 代次达到 179，未生成简报或取得飞书回执。

群内普通问答和草稿使用当前群公开资料。需要本人资料的要求由语义规划识别，受众标记独立于同一工作的模型输入。新消息检索回执按消息内容、正式发送身份与可读权限复核。群检索以受理时间为界。原生执行的预算同时受执行租期和业务截止约束。Runtime 明确返回不可恢复的工作绑定冲突时，Gateway 在当前群授权有效的情况下投递一次办理状态。

回归入口包括 TestGroupDraftRetryKeepsNativeInput、TestGroupImmutableConflictDeliversOneFailureReceipt 及真实模型 TestLiveGroupWeeklyBriefDelivery。最后一项从群入站原句验证正文包含本周群证据、回复原消息、正式简报库未发生写入。
