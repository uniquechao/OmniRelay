# 个人 API Key 与远程调试

每位已启用用户可在工作台头像菜单管理个人 API Key。浏览器会话和 CSRF 用于创建与撤销，HTTPS Bearer 用于业务 API，业务接口继续使用原账号与项目授权。密钥摘要与公开标识分开存储。每把密钥默认有效 30 天，每账号每环境最多 10 把有效密钥。停用账号的事务会一并撤销密钥。

独立 PostgreSQL 回归覆盖跨账号列表与撤销隔离、普通业务写入、禁止用密钥再签发、过期、撤销、停用后重新启用账号。候选验收从浏览器签发临时密钥，从独立客户端核对身份、向本人的项目 Bot 发问，再在工作台撤销并检查下一次请求。

候选版本 `3bd9002` 的真实 HTTPS 验收已通过。隔离成员使用 Bearer 收到带本人身份和项目署名的模型回复，重复请求复用工作 ID。无会籍的项目返回 403，撤销后本人查询和发送消息都返回 401。审计中各有一次签发和撤销，测试密钥已清理。

## 个人 Harness 接入

个人 Harness 可通过独立命令 `omnirelaycli` 访问工作台业务 API。密钥持有人是调用者。项目 PM 保留自己的项目身份、权限及署名。CLI 支持当前账号、项目目录和概览、提交 PM 问题和读取本人的项目消息。提问时由客户端提交稳定请求标识，以便中断后复用同一工作。

- CLI 本地回归通过。受控 HTTPS 服务验证 Bearer 身份、翻页、提交与读取消息、重定向处理、401、403 和 409 的非零退出状态。`go vet ./cmd/omnirelaycli` 通过。
- 2026-11-22 使用本次 Linux amd64 可执行文件及获准的管理员个人调试密钥在正式 HTTPS 入口只读验证。本人身份和项目目录查询成功，合成的范围外项目消息查询返回 403。本轮 PM 提交仅在本地 HTTPS 回归验证。
