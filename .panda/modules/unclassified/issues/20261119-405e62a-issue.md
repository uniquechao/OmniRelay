用 React 实现密码及飞书登录、账号资料、改密、退出、工作台总览与响应式导航。由同一个路由定义生成桌面和移动导航、标题、面包屑及合法站内目标匹配。Go 独立校验 OAuth 返回路径和实际访问权限。接入已合并 B2 的正式页面和历史入口。提供可供后续项目、文件、消息页面复用的参数化路由模式和测试样例。

## 原型扫描与范围补充

- 用户补充要求将系统视觉效果、全局样式和原型「开发者」全部元素封装为后续页面可直接使用的组件。原型六个入口为列表页、表单页、信息展示页、组件列表、工作台布局说明和色彩系统。
- 本机 Chromium 跑通原型演示登录及账号菜单。1366×900 下品牌区宽 683px、表单宽 360px；390×844 下品牌区在上，高 322px、表单宽 354px；主按钮均高 44px。窄屏启用减少动态效果。原型布局说明约定侧栏 166/52px、顶栏 46px、窄屏分组导航及内容区独立滚动。
- 当前 React 公共入口仅提供 Entry。开发者示例跨 OmniRelayUI、OmniRelayContent、OmniRelayLoading 和主题模块，既包含纯样式，也包含直接挂载 DOM 的列表、树、富文本、选择器及浮层。B2 生产页仍由 web/app.js 挂载。需系统规划明确共享组件与现有 DOM 模块的状态、焦点、事件清理和样式归属。默认生产切换归既有末项。
- 本轮完成原型测量和代码盘点，尚未修改业务实现或运行迁移验收。

- `tests/integration/react_components.test.mjs` 四组视口和主题通过，覆盖键盘操作、表单提交、草稿关闭、焦点恢复、实际动效帧、剪贴板和十处原型样式对照。定向类型检查通过。本 issue 属于 unclassified，当前索引没有对应的 MODULE.md。

## 子任务 2 实施与验收

- React 预发布工作台接入登录、概览、账号与响应式导航。统一路由定义位于 `frontend/src/routes/targets.ts`；B2 和已上线的项目、网盘、机器人记录用可取消的既有业务页挂载，保留正式功能与历史入口。新增资源模式只在测试注册表开放。
- Go OAuth 回调独立校验原始路径、别名、导航能力、系统分项和资源读取权限。项目读取复用角色服务，会话读取复用消息服务的授权范围。前后端共同消费路径样例，生产入口及部署切换沿用先前约定。
- 工作台等待草稿决定和会话复核后提交路由；历史条目记录位置，快速后退再前进时丢弃过时复核，取消后恢复原位置。真实角色矩阵暴露的历史竞态已修复并连续两轮通过。
- 定向验证通过：严格类型检查、Vite 构建、路径契约与服务端资源权限测试、双入口检查、HTTPS 登录与草稿浏览器测试、隔离 PostgreSQL 16 与 Go HTTPS 的五账号角色矩阵、飞书 OAuth 成功及错误回调联调。飞书提供方使用受控替身。逐项组件与视觉验收记录在 `design/engineering/react-components-acceptance.md`。本轮未执行系统最终门禁。
