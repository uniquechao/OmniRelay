# #20261119-f23b62a 飞书通讯录同步自动标记离职并回收账号访问

## 原始需求

用户确认的产品规则：原来在册的人员在完整同步中确认飞书已无该用户，即标记离职。对已开通的本地账号自动停用并撤销所有会话，阻断飞书 OAuth、密码登录和既有会话继续访问。以租户、应用和 Open ID 核对前后记录。复用 internal/directory 的完整分页、范围复核、快照和租约机制。首轮只建基线；当仅有部分授权范围、人员可能只是移出可见部门时，需要权威的用户不存在结果才能判离职。使用持久化状态让原在册人员消失后仍能在有权限的账号视图看到离职状态和时间，目录授权收窄后不得继续展示旧组织路径。沿用 internal/access 的账号停用、权限版本、最后管理员和审计约束，按既有锁顺序在事务内完成有效的状态变更、会话删除与审计。记录系统触发及同步批次。更新产品规则、接口契约和 issue 过程页。涉及 internal/directory、internal/access、internal/identity、迁移及用户管理页。

## 实施记录

- 当前 issue 归属 `unclassified`，模块索引未登记模块，当前目录没有 `MODULE.md`。沿用工作分支及 A1 人员投影，账号视图只补充持久化离职状态与确认时间，组织路径仍来自当前可见快照。
- `internal/directory` 完整读取后按同一租户、应用、Open ID 和授权摘要核对历史人员。部分授权下，单人查询只采信通讯录明确的不存在响应。整组织也用单人查询排除跨部门漏读，并接受目录缺失后该查询返回明确离职。权限范围发生变化的批次只更新快照和基线。
- `internal/access` 先取得组织权限锁，再由目录锁定来源和租约。离职、账号停用、权限版本递增、会话删除和系统审计与发布同事务。受保护的管理员保留账号，后续同步或管理员操作可在转交权限后完成停用。
