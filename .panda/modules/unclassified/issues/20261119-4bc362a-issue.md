# #20261119-4bc362a 前端：接入系统级角色、默认普通用户和系统运维菜单权限

## 原始需求

执行代理必须为 Codex。按本计划共享协议实施，可与后端并行，先用固定契约样例验证，最终联调真实接口。读取项目约定及相关过程页；遵循 omnirelay-frontend、Impeccable、Web Design Guidelines 技能，复用现有主题、表格、抽屉、表单和对话框。

重点文件为 web/system-api.js、web/admin.js、web/app.js、web/login.js、web/account.js、web/feishu-bot.js。角色范围、筛选、详情、授权表单和用户详情中的组织级改为系统级；组织结构和所属组织文案继续表达通讯录含义。角色定义从 GET /system/roles 获取，适配真实 wire role ID，替换前端硬编码的权限事实来源。项目级展示和授予规则沿用现状。

普通用户显示默认拥有，不伪造 grant ID，也不提供手动授予/撤销。结合 Account.systemRoles 与真实授权记录正确展示启用和停用用户。按 access.admin 控制子菜单、access.navigation 控制一级菜单、access.default_route 控制落点、access.permissions 控制具体操作；缺省拒绝。移除以 system_admin 等角色名直接推导操作权限的逻辑。

运维者的用户与角色页面支持只读浏览，允许同步与连接检测；账号开通/启停、授权/撤销、保存配置和 Bot 启停按能力限制。覆盖桌面侧栏、移动导航、直达路由、前进后退、登录 return_to、重新登录和撤权。无权 return_to 回到 default_route，避免循环跳转；兼具项目授权时沿用原项目能力。

保留 CSRF、Bot 条件请求和检测幂等键。401 处理重新登录及草稿，403 刷新能力且避免无限重试；保留仍有读取权限的页面。验证桌面/窄屏、浅深色、键盘焦点、只读态、空态、错误态和未保存草稿。没有独立确认稿的新状态明确记录验收边界。

## 实施结论

Codex 在系统准备的分支上连续完成。已核对已发布计划、共享协议、后端过程页与当前接口实现。模块索引只有标题，本问题的 `module_uid` 为空，无已登记的模块文档可更新。

- `web/system-api.js` 和 `web/admin.js` 按服务端角色目录展示名称、范围、授权方式和权限说明。默认角色人数按启用账号的有效角色统计；授权操作使用真实角色和记录标识。停用保留授权记录，重新启用后恢复默认角色。通讯录仍显示组织结构与所属组织。
- `web/app.js`、`web/login.js` 和 `web/account.js` 按会话能力处理桌面与移动导航、白名单返回地址、默认落点、会话恢复及页面切换。403 合并并发能力刷新，仍可读时留在原页面；401 清除当前编辑状态并记住返回地址。
- 用户管理和 `web/feishu-bot.js` 独立判断账号管理、角色管理、同步、配置及检测能力。沿用原抽屉、表单、确认对话框、主题和项目选择规则。

## 定向验证

- `tests/contract/directory_client.test.mjs` 和 `tests/contract/feishu_bot_client.test.mjs` 共 7 项通过，包括真实角色标识、有效角色与真实授权分离、项目授权请求体、分页快照及 CSRF、ETag、If-Match、Idempotency-Key。
- `tests/integration/feishu_login_browser.test.mjs` 的 5 项固定响应浏览器用例通过，覆盖无能力、运维叠加项目导航、回跳白名单、前进后退相关导航恢复、401、密码登录和主题。该脚本的可选外部 Go OAuth 用例未启用。另行使用真实 Go HTTP 服务及隔离 PostgreSQL 16 验证了以下业务路径。
- 四类测试账号的默认落点、桌面侧栏和移动选择器与服务端一致。运维者浏览用户、角色和 Bot，目录同步、连接检测分别收到 202。管理员真实授予审计角色、停用、启用、撤销均通过；停用期间仍能查看真实授权，默认角色随有效状态恢复。
- 两个浏览器上下文中，管理员撤销运维角色后，旧会话的下次检测收到 401 并返回登录。另验证管理员在 Bot 草稿未保存时会话失效，登录保留目标路由且草稿被清除。固定 403 和写权限变化验证了仅刷新一次能力、保留可读 Bot 页面、移除配置表单。角色草稿离开时可选择放弃，关闭只读抽屉后焦点返回原行。
- 使用 1366×900 和 390×844 两种视口，各检查浅色与深色。正式页面沿用 480px 桌面抽屉和窄屏全宽布局。已运行仓库原型；系统级默认角色与运维只读组合没有独立确认稿，验收依据为共享协议及现有组件。项目授权叠加通过固定导航能力验证，正式项目权限源接入沿用后端现状。浏览器联调没有向真实飞书发起出站请求。
