## 实施与验证

- `internal/identity/identity.go` 在原子消费并验证浏览器绑定后，使用固定的 `cancelled`、`denied`、`unavailable` 登录回跳。无效事务继续返回 400。`internal/identity/feishu.go` 将飞书限流和服务端错误归为 `unavailable`，账号准入仍依赖经过验证的租户、应用和 Open ID。
- 工作台返回路径使用显式白名单，包含 `/#/system/feishu-bot`。部署前已保存的旧路径在成功回调前重新校验，超出白名单时回到 `/`。Bot API 对回跳后的访问独立鉴权。
- `internal/identity/identity_test.go` 和 `cmd/omnirelay/backend_test.go` 在隔离 PostgreSQL 上覆盖拒绝与成功回跳、PKCE S256、浏览器绑定、重放和并发消费、旧会话替换、停用与撤权、退出 204，以及回跳目标重新鉴权。密码登录和改密回归通过。
- 应用日志回归确认固定错误码可观测，回调查询串、授权码、令牌、Cookie 和飞书诊断文案未被应用日志采集。仓库后端未接入 APM，已在 `design/engineering/feishu-integration-contract.md` 记录入口与出站采集约束。真实飞书及部署侧代理和 APM 的联调由预发布验收覆盖。
- OAuth 契约样例校验通过。`go test -race` 的 `TestOAuthSessionLifecycleWithPostgres` 和 `TestBackendFeishuAdmissionAndRevocation` 均在隔离数据库上通过。当前索引无模块条目，`unclassified` 没有 `MODULE.md`，长期约束已写入现有接入契约。
