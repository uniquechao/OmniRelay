## 本轮实施与首验记录

候选入口在 `cmd/omnirelay/candidate_web.go` 按实际 Pod、运行和期限读取管理服务发布的绑定，使用候选 PostgreSQL 的登录事务、账号与会话。Cookie 名、会话摘要和登录事务签名区分运行。React 使用现有构建入口。新增的 `candidate-operation` 在受控环境读取网页配置，以运行、固定回调、应用、租户及指定身份约束换码；套接字调用有次数上限和独占尝试记录。候选仅持短期运行凭据。管理端和候选 Pod 只共享专用只读目录，通过精确 UID 的 ACL 提供连接和读取权限。

`internal/directory` 用授权范围与登记样本的交集驱动采集，在取样前和发布前复核范围。范围摘要变化时隐藏旧快照；目录返回前裁剪样本外部门字段。管理端按实际受控进程的二进制摘要、成员页和续页、去重人数、字段缺项计数留证。`internal/access` 与业务 API 同时约束无项目会籍的运维访问。入口与操作约定见 `deploy/k8s/candidate/README.md`。

本地定向验证使用隔离 PostgreSQL、真实 Go 服务、Chromium、React 构建入口和合成平台响应。候选入口到换码回跳、同一身份的落点与 `/api/v1/me`、取消、同源隔离、过期、重放、浏览器绑定、未开通、停用及撤权旧会话通过。网页配置解密到身份读取和目录取样的适配器回归通过。已知三人三部门样本实收三人，成员续页一次，同一人保留两条可见部门关联；受限用户组、范围收窄、坏页和临时失败已有定向验证。五类本地账号的菜单、直达路由、后端 API 和登录落点通过，项目叠加场景采用本地会籍。管理入口三项回归通过。脱敏记录位于 Git 忽略的 `deploy/k8s/private/candidate/20261120-6d3062a.json`。
