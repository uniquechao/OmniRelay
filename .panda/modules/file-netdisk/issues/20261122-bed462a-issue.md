# #20261122-bed462a 文件网盘 滚动区域不对

## 原始需求

只留列表区域滚动 固定页面头部和页码部分（页码部分如果超出页面就在最下面 如果不超出就和列表区域一样大就行）

## 澄清与设计

截图中工作台面包屑仍可见，但网盘标题、分类和分页已随整页滚出视口。长列表应只滚动文件行，表头、分类、搜索筛选和分页保持可见；短列表的分页紧跟内容。

## 设计与实施

正式路由将网盘分配为普通内容布局，原型已使用共享列表布局。复用共享组件的滚动区与吸顶表头，在网盘容器中限制长列表高度，并允许短列表按内容收缩。

## 修改文件与测试

- `frontend/src/features/workbench/Workbench.tsx` 将网盘路由接入共享列表布局。
- `design/prototype/omni-relay-drive.css` 保留分类栏高度，列表随内容增高，到达可用高度后由内部滚动区承接溢出。
- `tests/integration/chat_reader_browser.test.mjs` 新增正式路由回归。在 1366 × 844 浅色和 390 × 844 深色视口，使用 51 条测试文件，实测首屏 50 条、末页 1 条及空分类。键盘滚动时页头、分类、工具栏、表头和分页位置稳定，长列表分页位于页面内容区底部，末页和空分类的分页紧跟内容。

## 集成核对

保留同步进度和列表滚动两项独立回归。合并后的生产构建通过，Chromium 在桌面与窄屏下验证了刷新读取进度、长列表仅文件行滚动、短页及空列表分页位置。两项用例均通过。

## 结果与遗留事项

已完成。定向浏览器回归和 `git diff --check` 通过，原始需求无遗留。
