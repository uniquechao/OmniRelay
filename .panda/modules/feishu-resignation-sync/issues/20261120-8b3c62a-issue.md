# #20261120-8b3c62a 群聊中在飞书中找不到的人自动标记为离职

## 原始需求

群聊中在飞书中找不到的人自动标记为离职
详情中标记离职（icon），头像人名后面也标记红色小字离职

## 澄清与设计

截图对应群消息的发送人及点击姓名或头像打开的人员卡片。复用通讯录同步和人员投影，对仅出现在历史群聊中的人员补查飞书身份。

## 设计与实施

同步按租户、应用和人员去重，优先检查未核实、最久未核实的群消息发送人。飞书明确返回人员不存在或已离职时标记，查询失败保留上次确认结果。重新入册后以当前快照为准。群聊补查结果独立于账号停用。

群消息、搜索结果和成员姓名使用主题红色小字。人员卡片附离职图标与文字，头像与姓名均可打开。

## 修改文件与测试

- `migrations/0022_chat_sender_status.sql`、`internal/directory/` 与 `internal/chat/` 完成核实、发布及授权读取。
- `web/chat-reader.js` 和 `design/prototype/omni-relay-ui.{js,css}` 实现姓名标记及卡片图标。
- 隔离 PostgreSQL 下通过 `TestGroupSenderDeparture`、`TestSynchronizationClaimsPublicationAndAccess`、`TestChatReadAuthorizationAndPagination`、`TestProjectChatReaderScope`，迁移顺序检查通过。
- 前端构建和机器人记录浏览器定向用例通过，覆盖从头像及姓名打开离职卡片。

## 结果与遗留事项

已完成。历史群消息可随目录同步获得离职标记。每轮使用剩余请求预算分批核实；验证使用模拟飞书响应、实际 PostgreSQL 和 Chrome。
