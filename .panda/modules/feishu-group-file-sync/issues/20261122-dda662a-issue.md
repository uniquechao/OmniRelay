# #20261122-dda662a 文件同步进度改成异步

## 原始需求

文件同步进度改成异步请求 不用轮询，刷新查看进度即可不需要轮询请求，
还有这里内容加载应该用最小 loading 限制整体高度

## 澄清与设计

两张截图都标出文件网盘标题下的同步摘要。刷新采用浏览器刷新页面；分类、筛选、停留和后台任务状态变化均不触发新的进度请求。

## 设计与实施

当前分支尚无同步摘要和对应接口。沿用历史实现的接口和计数口径，按本分支已绑定项目、项目成员和可读群的规则获取快照。摘要与文件列表独立加载，等待期间只占一行。

## 修改文件与测试

- `web/drive.js` 与 `design/prototype/omni-relay-drive.css` 在标题下显示同步摘要。使用共享行内加载样式，收到快照后替换为可换行的文字。离开页面取消请求，读取失败时提示刷新。
- `internal/drive/http.go` 与 `internal/drive/progress.go` 提供只读快照接口，复用会话认证、群访问检查和现有来源视图。
- `internal/drive/group_sync_test.go` 的 `TestDriveSyncProgress` 在独立 PostgreSQL 16 上通过，覆盖未扫描消息、待解析知识库消息、待同步、需处理、已完成，以及群不可读或解除绑定后的统计。
- `tests/integration/chat_reader_browser.test.mjs` 的两项定向用例通过。在 1366 像素浅色和 390 像素深色视口，慢响应时提示高度均不超过 24 像素，分类与列表可用；成功和失败后各推进一分钟均无进度轮询，刷新才读取新快照。图片与视频预览、下载用例也通过。

## 结果与遗留事项

原始需求已完成，使用系统准备的分支连续实施。无需求内遗留。
