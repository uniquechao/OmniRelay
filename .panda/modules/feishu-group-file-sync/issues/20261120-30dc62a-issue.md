# #20261120-30dc62a 飞书群聊资源同步到文件网盘方案实施

## 原始需求

方案已写好：[飞书群聊资源同步到文件网盘方案](design/specs/omni-relay-group-file-sync-design.md)。

核心机制：

- 附件、图片、视频和文档统一采集，原件存 MinIO，网盘提供列表、预览和下载。
- **文件自动继承来源群的项目归属**。
- 同一文件跨项目群分享，保留一份内容、多条来源和多个项目关联。
- 群改绑或来源撤权时重新计算归属，保留其他有效来源及人工关联。
- 明确同步重试、版本去重、权限检查和验收步骤。

## 澄清与设计

按用户答复保留旧关联原记录供核对。迁移保留旧表，从最后一次有效插入的操作者审计恢复可确认的人工关联。无法判定来源的记录不计入有效归属，用户可通过现有文件归属编辑器重新确认。方案原文从主工作树同路径读取。

## 设计与实施

- 复用现有群历史、消息索引和后台领取机制。独立图片、富文本图片和视频按消息 ID 与资源 key 读取。Wiki 解析真实对象后与直接文档链接共用逻辑文件，读取时重新核对节点和原消息。Docx 保存纯文本正文。
- 在私有临时文件中流式校验长度和 SHA-256。上传前登记对象，以租户和摘要复用私有对象。上传成功并复核授权后，同事务提交来源可读版本、对象发布标志及完成状态。旧版 PostgreSQL 分块沿用原读取路径。
- 群继承项目由可读消息来源和当前绑定推导，与人工关联取并集。每个读者复用群聊成员检查，再核对 Bot、群、消息、资源与具体版本。项目入口与网盘使用同一文件和版本标识。
- 领取时间和凭据代次约束任务提交。失败按类别退避，限流遵循平台等待时间。未发布对象有 24 小时重试宽限期，后台只回收超期且未发布的对象。预览、原件及视频分段统一通过服务端，长对象传输期间继续复核。

## 修改文件与测试

- 后端涉及 `migrations/0023_group_file_sync.sql`、`internal/drive/`、`internal/feishu/files.go`、`internal/project/panels.go`、`cmd/omnirelay/server.go`。网盘抽屉、归属编辑、项目和下载入口位于 `web/drive*.js`、`web/projects.js` 与 `web/workbench.css`。部署模板补齐私有暂存卷及未发布对象回收权限。
- 使用隔离的 PostgreSQL 16 和项目指定的 Silo `RELEASE.2026-11-12T00-00-00Z`，通过 TLS 实际读写对象。定向 Go 回归通过，覆盖旧关系迁移、旧分块、绑定前历史、跨项目分享、消息重投、Wiki 与直接链接合并、改绑与撤权、上传后失败恢复、无引用对象回收及分段授权。匿名访问测试桶返回 403。
- 浏览器验证使用受控接口响应。覆盖桌面和手机的浅色与深色网盘、人工项目编辑、来源定位、预览翻页、图片解码、版本下载、不支持的视频格式及撤权后的抽屉清理。工作台资源构建和 `TestPreviewUI` 通过。

## 收尾自检

静态核对发现，项目入口在多群分享时间与版本同步时间顺序相反时，可能配错原消息链接。已改为从选中版本对应的来源取群和消息标识，并在 `TestCurrentGroupAndVersionAccess` 补充这一场景。已同步修正 `TestBackendFeishuAdmissionAndRevocation` 的旧首页断言，改为检查 React 根节点、内容安全策略及首页实际引用的脚本和样式。本轮仅静态复核，以上改动的运行结果由系统门禁确认。

## 集成核对

目标分支已使用 0022 核实群聊人员状态，本批文件同步迁移顺延至 0023，SQL 内容保持原样。升级测试现在先执行前 22 项迁移，再验证第 23 项对旧关联的处理。迁移顺序测试通过。旧关联升级用例因本轮未配置隔离 PostgreSQL 而跳过。

## 结果与验收步骤

1. 在两个已绑定不同项目的测试群分享同一文档，并投递附件、图片和视频。核对网盘文件 ID、每条来源、项目标签、实际下载字节和版本；重复投递应复用版本。同一 Wiki 节点需由测试 Bot 获得读取权限。
2. 在只对第二群完成采集后产生新正文。分别用两群成员验证历史列表、原件和预览，只能读到各自有效来源取得过的版本。
3. 添加人工关联，再改绑、解绑或撤回一条分享。核对旧项目入口、网盘筛选和总数、其他群贡献及人工标签。撤回最后一条可读来源后，使用旧下载、预览和 Range 地址复核拒绝访问。
4. 中断对象上传或版本提交并重试，核对成功前的文件状态、版本数和对象摘要。对旧分块样本验证既有文件地址。迁移前缺少来源证据的历史版本继续留存，仅有来源记录的版本对外开放。

本次完成代码和隔离环境定向验证。飞书响应及撤权场景使用受控样本，未连接真实业务群或执行生产部署。
