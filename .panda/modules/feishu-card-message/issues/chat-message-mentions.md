# 群聊历史消息中的 @ 姓名

截图中的一条群消息连续出现 `@_user_1`、`@_user_2`、`@_user_3`，另一条再次从 1 编号。飞书把提及姓名放在每条消息自己的 `mentions` 中。实时事件和历史适配器原先只归档正文，阅读器直接显示了占位符。

实时事件、历史分页和发送回执现在都保留同一消息的提及映射。迁移 36 为现有消息增加提及姓名字段。原始正文继续用于资源绑定。普通文本按完整编号一次替换，富文本按结构化 `at` 节点显示；确认不了姓名的富文本提及显示「@成员」。搜索索引和阅读接口使用同一份展示文字。同一版本的互补数据在事务内合并，编辑时更新映射，撤回时清除姓名和正文。

既有根会话在下一轮全量历史同步中补齐可读取的消息，话题沿用已有的独立同步游标。回归使用本地 PostgreSQL、模拟飞书输入及工作台的 Chromium 浏览器，覆盖即时与历史消息、个位及两位编号、重复投递、编辑、撤回、按姓名搜索和项目会话阅读器。
