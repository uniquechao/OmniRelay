# #20261122-be0362a 文件网盘的来源字段

## 原始需求

隐藏红框内容，只留一个 icon 定位

## 澄清与设计

列表继续显示截图红框上方的群名。每条不同的原消息配一个定位图标，同一消息的重复来源合并。

## 设计与实施

全局网盘、项目文件和交互原型共用来源图标。列表隐藏分享人、时间与操作文字，文件详情继续显示完整来源。图标支持键盘访问和触屏点击，读屏名称包含群名及来源序号。

## 修改文件与测试

网盘渲染在 web/drive.js 和 web/drive-metadata.js。共享的标记、样式及原型位于 design/prototype。Chromium 定向回归覆盖同群多个来源、重复来源去重、消息跳转、返回回焦、项目内路由，以及桌面与手机两种主题。

## 结果与遗留事项

本地生产构建、TypeScript 检查和浏览器定向用例通过。浏览器使用模拟飞书数据。
