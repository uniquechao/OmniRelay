# #20261120-78da62a 消息里面 文件和飞书文档要能预览

## 原始需求

文件和飞书文档要能点击预览（右侧抽屉展示）
图片要能预览展示

## 澄清与设计

- 按截图确认验收场景：知识库链接、电子表格链接、妙记链接与 PDF 附件可在右侧抽屉查看内容，图片消息可查看图像。
- 聊天附件和图片沿用会话与原消息授权读取飞书消息资源。飞书云文档按当前用户的飞书权限读取，抽屉提供只读内容预览。

## 设计与实施

- 机器人记录与项目关联群共用 `web/chat-reader.js`。`internal/chat/http.go` 已对两个入口按会话和项目范围鉴权，`internal/feishu/files.go` 已实现消息文件资源的读取。
- `internal/chat/message_preview.go` 提供按原消息授权的资源读取。服务端匹配归档消息中的资源，核验飞书原消息状态，并在响应前复核归档状态。聊天附件按需读取原件，复用 `internal/drive/preview.go` 的有界转换能力，无需先同步到网盘。图片经同源接口按需在消息中显示，并可点击放大。
- `internal/identity/preview_grant.go` 使用既有 OAuth 回调与 PKCE 接入独立的按需只读授权。凭证在服务端内存中按资源类型和工作台会话绑定，只在有效期内可用，退出时清除。原登录流程继续按现有约定完成身份查询。`internal/feishu/message_preview.go` 按用户权限解析知识库节点并分页读取表格。`web/chat-preview.js` 复用右侧抽屉和预览渲染，提供加载、重试、撤回、授权和格式提示。完成授权后回到原消息并重新打开预览。

## 修改文件与测试

- 隔离 PostgreSQL 定向用例覆盖两个入口的资源匹配、项目范围、越权和撤回，以及 OAuth 会话隔离与回调重放。飞书模拟传输覆盖消息图片、知识库解析、分页表格、妙记及拒绝访问。现有网盘转换样本验证含真实 PDF 内容，均通过。
- Chromium 定向用例覆盖桌面机器人记录、手机项目关联群、PDF 分页、图片放大、正文中的飞书链接、授权回跳，以及现有卡片、网盘预览和项目聊天宿主，均通过。
- 前端类型检查与变更格式检查通过。
- 额外的 `TestBackendFeishuAdmissionAndRevocation` 停在旧静态登录页的 `id="password-login"` 断言。现有 React 入口在客户端渲染登录表单。相关代码已编译，当前预览回归由独立用例覆盖。
- 收尾静态复核修正了同一消息内链接共用前缀时的匹配，并让消息刷新后移除的资源关闭正在打开的预览。新增同前缀链接回归断言，本轮按约定交由系统门禁执行。

## 结果与遗留事项

- 已在两个聊天入口交付文件与飞书文档抽屉、图片展示和放大。飞书授权与文档内容读取使用模拟上游验证，真实租户权限配置未联调。
